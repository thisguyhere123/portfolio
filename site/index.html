About

I like problems where the data is messy and the answer has to be right. My most recent site, Who Owns Your Hospital?, turns Medicare ownership records into a map anyone can search to see whether private equity owns their local hospital. I wrote the classification, built the site, and run the server it lives on.

I also built Scrape Anything, a web-scraping product with billing, a public API and webhooks, and an AI research pipeline that refuses to print a number or claim it can't trace to a source. When I want to make something just for fun, I make games in Unity.

I work in TypeScript, Python and C#, and I care about tests, honest limits, and software that does what it says.
